Standard Execution

No pacing mechanism is used. Event callbacks are fired 1:1 on every trigger. If you drag, scroll, or resize, this can happen dozens of times per second, overloading JavaScript CPU cycles and causing DOM rendering bottlenecks (layout thrashing).

Throttling (Bóp băng thông)

Limits execution frequency by locking execution for a certain delay after a trigger. It ensures periodic execution (e.g. at most once every 400ms). Perfect for scroll loading, game loops, or progressive UI updates during animations.

Debouncing (Chống rung)

Groups multiple sequential triggers into a single call. It resets the timer on every incoming event and only executes once the event stream quietens down for the full delay duration. Excellent for search autocomplete input or window resizing.
